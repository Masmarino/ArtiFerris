Once the pod is ready and the ACME challenge completes (a minute or two), it'll be reachable at:
  https://{{ .Values.ingress.host }}

Check certificate issuance with:
  kubectl get certificate -n {{ .Release.Namespace }}
{{- end }}

Every organization subdomain (e.g. acme.{{ .Values.ingress.host }}) is covered by a wildcard
TLS certificate issued via DNS-01, through the ClusterIssuer named
{{ .Values.ingress.clusterIssuer }}. That issuer is created and owned by the separate
cm-webhook-ovh Helm release (see helm/cert-manager-webhook-ovh/README.md) — this chart only
references it by name, it does not create it.

Log in with:
  username: {{ .Values.hangar.bootstrapAdminUsername }}
  password: kubectl get secret {{ .Release.Name }}-secrets -n {{ .Release.Namespace }} -o jsonpath='{.data.HANGAR_BOOTSTRAP_ADMIN_PASSWORD}' | base64 -d
(only works before the users table has its first row — the app ignores this value after that;
change the password once logged in)
